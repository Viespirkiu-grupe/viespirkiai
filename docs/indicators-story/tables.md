## Pastabos

- Skaitymo teisė tikrinta `has_table_privilege(current_user, ..., 'SELECT')` — atspindi vartotojo `rimvydas` teises, ne kito vartotojo (pvz., programos) teises.
- Sąraše tik `public` schemos lentelės. Schema `repack` (pg_repack) vartotojui neprieinama.
- Rodiniai (`v_*`, `liteko2SprendimaiView`, PostGIS `geometry_columns`/`geography_columns`) į sąrašą neįtraukti — čia tik lentelės.
- `v_*` rodinių lentelės surinktos iš SQL failų `modules/mcp/analyst/views/`, ne iš `pg_depend`, nes rodinių apibrėžimų skaitymas ribojamas tų pačių teisių.
- Vartotojas `rimvydas` neturi SELECT teisės nė vienam `v_*` rodiniui (`permission denied for view ...`), nors visi šeši rodiniai duomenų bazėje egzistuoja. Rodiniai vykdomi savininko teisėmis, todėl nepakanka gauti teises į bazines lenteles — reikia GRANT SELECT ir patiems rodiniams.
