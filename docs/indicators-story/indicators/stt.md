# STT indicators

A flag is a reason to review a procurement, not proof of fraud, corruption, or illegality.

Normalized from recurring procurement risks in [STT corruption-risk analyses](https://www.stt.lt/korupcijos-prevencija/korupcijos-rizikos-analizes/7470), recommendations, and Lithuanian public-procurement findings. These are analytical catalogue labels, not official STT codes.

| Code | Indicator |
|---|---|
| STT-I01 | No documented market research before procurement |
| STT-I02 | Only one supplier consulted or invited |
| STT-I03 | Procurement receives a single bid |
| STT-I04 | Technical specification tailored to a particular product or supplier |
| STT-I05 | Disproportionate qualification requirements restrict participation |
| STT-I06 | Repeated awards to the same supplier |
| STT-I07 | Buyer spending concentrated among few suppliers |
| STT-I08 | Unjustified non-competitive or negotiated procedure |
| STT-I09 | Purchase split to avoid a procedural threshold |
| STT-I10 | Estimated value unsupported or inadequately calculated |
| STT-I11 | Conflict of interest not declared or managed |
| STT-I12 | Buyer official has personal or business ties to supplier |
| STT-I13 | Evaluation criteria allow excessive discretion |
| STT-I14 | Bid rejected on weak or inconsistent grounds |
| STT-I15 | Procurement documentation or decisions are incomplete |
| STT-I16 | Contract terms materially changed after award |
| STT-I17 | Contract price increased without sufficient justification |
| STT-I18 | Delivered quantity or quality differs from contract |
| STT-I19 | Contract supervision or acceptance controls are weak |
| STT-I20 | Supplier support/donation relationship with purchasing institution |
